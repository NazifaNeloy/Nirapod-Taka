## 📖 Overview

**Nirapod Taka (নিরাপদ টাকা)** is a mobile-first, lightweight web application designed to protect citizens in Bangladesh from financial fraud, fake MFS (bKash/Nagad/Rocket) threats, phishing links, and deceptive lottery schemes. Built specifically with budget Android smartphones and slow 4G network performance in mind, it delivers instant detection with explainable, transparent risk verdicts.

---

## ✨ Key Features

- **🎯 Interactive 3D Scam Threat Visualizer**: Zero-dependency CSS 3D perspective phone simulation with tactile pointer/touch parallax tilt and floating warning bubbles.
- **🔍 Multilingual Scam Checker**: Instant risk scoring (Safe, Suspicious, Scam) with transparent, highlighted deception signals and explainability drawer (*"কেন?"*).
- **📊 Real Financial Impact Data**: Grounded in official 2025 cyber fraud statistics (81,423 cases, ৳926.01M losses, 8.7% MFS recovery rate).
- **🇧🇩 100% Bangla-First & English Localization**: Seamless bilingual toggling with native Bangla numeral formatting (`১২৩৪৫৬৭৮৯০`).
- **👤 User Profile & 64 Districts**: Localized profile management with district tracking across all 64 districts of Bangladesh.
- **📜 Verification History & Badging**: Search history with CSV (UTF-8 BOM for Excel) and JSON export, plus gamified community safety badges.
- **🔒 Privacy & Security by Design**: Tokenless client memory architecture with httpOnly cookie authentication, zero DOM injection (`dangerouslySetInnerHTML`), and zero tracking.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, React Router v7
- **Styling**: Tailwind CSS v4, Pure CSS 3D Transforms (Zero heavy WebGL/Three.js dependencies)
- **Testing**: Vitest, React Testing Library, JSDOM
- **Build Tool**: Vite 6

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/NazifaNeloy/Nirapod-Taka.git
cd Nirapod-Taka/frontend

# Install dependencies
npm install

# Start development server
npm run dev -- --host
```

Visit `http://localhost:5173/` in your browser.

### Running Tests

```bash
npm test
```

### Building for Production

```bash
npm run build
```
